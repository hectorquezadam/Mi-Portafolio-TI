# 📚 Gestión de Biblioteca Académica
Sistema para la administración de préstamos de libros, socios y editoriales.

### 🛠️ Tecnologías Aplicadas
- **Base de Datos:** Modelado complejo con relaciones Many-to-Many y tablas intermedias.
- **ORM Django:** Consultas optimizadas con `select_related` y `prefetch_related`.

### 🔍 Puntos Clave
- **Panel Administrativo:** Configuración avanzada del Admin de Django para gestión masiva.
- **Integridad de Datos:** Validaciones personalizadas para fechas de préstamo y devolución.
