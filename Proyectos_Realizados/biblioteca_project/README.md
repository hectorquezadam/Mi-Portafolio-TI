# 📚 Sistema de Biblioteca Académica
**Ejercicio de Aplicación: Relaciones de Base de Datos y ORM**

Una plataforma para gestionar el préstamo de libros en un entorno académico, enfocada en la integridad de los datos y las relaciones entre entidades.

---

## 🛠️ Tecnologías y Herramientas
- **Backend:** ![Python](https://img.shields.io/badge/-Python-3776AB?style=flat&logo=python&logoColor=white) ![Django](https://img.shields.io/badge/-Django-092E20?style=flat&logo=django&logoColor=white)
- **Base de Datos:** ![PostgreSQL](https://img.shields.io/badge/-PostgreSQL-4479A1?style=flat&logo=postgresql&logoColor=white) (Relaciones Many-to-Many).
- **Frontend:** ![HTML5](https://img.shields.io/badge/-HTML5-E34F26?style=flat&logo=html5&logoColor=white)

---

## 🌟 Puntos Destacados
- **Modelado de Datos:** Uso de tablas intermedias para gestionar préstamos entre Socios y Libros.
- **Optimización de Consultas:** Uso de `select_related` y `prefetch_related` para mejorar el rendimiento.
- **Admin Personalizado:** Configuración avanzada del panel de administración de Django para gestión de inventario.
