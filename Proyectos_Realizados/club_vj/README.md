# 🎮 Club V.J. - Catálogo Digital Dinámico
Este es el proyecto final del Módulo 6, diseñado para digitalizar el inventario de juegos de "Don Pedro".

### 🛠️ Tecnologías Aplicadas
- **Backend:** Python & Django 5.x.
- **Frontend:** HTML5, CSS3 y Bootstrap 5 (Diseño responsivo y Dark Mode).
- **Base de Datos:** PostgreSQL / SQLite con relaciones complejas (ForeignKey).

### 🌟 Características Destacadas
- **Lógica VIP:** El sistema identifica automáticamente lanzamientos del año actual y los marca como "EXCLUSIVO VIP".
- **Filtros Dinámicos:** Clasificación por plataforma (PS5, Xbox, Switch) y género.
- **Seguridad:** Gestión de perfiles de usuario y permisos de administrador.
